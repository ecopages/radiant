# Installation

The most common setup is `@ecopages/radiant` plus `@ecopages/jsx`.

```bash
bun install @ecopages/radiant @ecopages/jsx
```

## TypeScript Setup For JSX

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@ecopages/jsx"
  }
}
```
<br/>
Or enable it per file:

```tsx
/** @jsxImportSource @ecopages/jsx */
```

## Signals Standalone

If you only want the reactive core, install `@ecopages/signals` by itself:

```bash
bun install @ecopages/signals
```

## Which Packages To Install

- Install `@ecopages/radiant` when you want custom elements, decorators, context, and host rendering behavior.
- Install `@ecopages/radiant` plus `@ecopages/jsx` when you want the component-first TSX workflow.
- Install `@ecopages/signals` when you want the standalone reactive layer.
