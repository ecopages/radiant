# StringifyTyped
---

This utility function is used to stringify attributes in a typed way.
This is useful when you need to pass attributes to a component that expects a specific type.

Import `stringifyTyped` from `@ecopages/radiant/tools/stringify-typed`. It is a low-level serialization helper, not part of the main root client surface.

```tsx
import { stringifyTyped } from '@ecopages/radiant/tools/stringify-typed';

export const MyComponent = ({ value }: { value: number }) => {
    return <my-component complex-attribute={stringifyTyped<MyType>({ value })}></my-component>;
};  

// Output: <my-component complex-attribute="{&#34;value&#34;:1}"></my-component>
```


It can also produce JSON strings for lower-level helpers or transport payloads:

```tsx
import { stringifyTyped } from '@ecopages/radiant/tools/stringify-typed';

export const MyComponent = ({ value }: { value: number }) => {
    const hydrationPayload = stringifyTyped<{ value: number }, string>({ value });

    return <my-component data-payload={hydrationPayload}></my-component>;
};  
```

If you want to author a hydration payload as a child `<script>`, pass the JSON string as the script child content:

```tsx
import { stringifyTyped } from '@ecopages/radiant/tools/stringify-typed';

export const MyComponent = ({ value }: { value: number }) => {
  const hydrationPayload = stringifyTyped<{ value: number }, string>({ value });

  return (
    <my-component>
      <script type="application/json" data-hydration>{hydrationPayload}</script>
    </my-component>
  );
};
```

If you are hydrating an existing `ContextProvider` or `RadiantComponent` instance, the built-in helpers such as `renderComponent(...)`, `renderHostToString(...)`, `provider.renderHydrationScript()`, or `provider.renderHydrationScriptTag()` are still the most direct option. Those server-oriented helpers live under `@ecopages/radiant/server/*`.
