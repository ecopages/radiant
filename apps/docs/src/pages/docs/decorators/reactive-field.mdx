# @reactiveField (Removed)

<Banner type="warning">
  <Banner.Title>Breaking Change</Banner.Title>
  <p><code>@reactiveField</code> has been removed. Use <a href="/docs/decorators/state"><code>@state</code></a> instead — it is a drop-in replacement.</p>
</Banner>

## Migration

Replace all `@reactiveField` usages with `@state`:

```typescript
import { state } from '@ecopages/radiant';

@state count = 0;
```

See the [@state documentation](/docs/decorators/state) for full details.
