# @reactiveProp (Removed)

<Banner type="warning">
  <Banner.Title>Breaking Change</Banner.Title>
  <p><code>@reactiveProp</code> has been removed. Use <a href="/docs/decorators/prop"><code>@prop</code></a> instead — it is a drop-in replacement.</p>
</Banner>

## Migration

Replace all `@reactiveProp` usages with `@prop`:

```typescript
import { prop } from '@ecopages/radiant';

@prop({ type: String }) declare name: string;
```

See the [@prop documentation](/docs/decorators/prop) for full details.
