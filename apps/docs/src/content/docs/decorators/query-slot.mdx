# @querySlot

The `@querySlot` decorator queries projected light-DOM elements assigned to a `RadiantElement` slot.

Use it when a component accepts content through literal `<slot>` tags and needs to inspect the assigned elements after projection.

## Usage

```tsx
import { RadiantElement, customElement, querySlot } from '@ecopages/radiant';

@customElement('shell-card')
export class ShellCard extends RadiantElement {
	@querySlot({ name: 'heading' }) heading!: HTMLHeadingElement | null;
	@querySlot() body!: HTMLParagraphElement | null;
	@querySlot({ name: 'action', all: true }) actions!: HTMLButtonElement[];

	override render() {
		return (
			<article>
				<header>
					<slot name="heading" />
				</header>
				<div>
					<slot />
				</div>
				<footer>
					<slot name="action" />
				</footer>
			</article>
		);
	}
}
```

## Parameters

| Parameter | Type | Required | Description |
| :-------- | :--- | :------- | :---------- |
| `name` | `string` | No | Named slot to query. Omit it for the default slot. |
| `all` | `true` or `false` | No | Return every assigned element instead of only the first one (default: `false`). Must be a literal, because it picks the field type. |
| `cache` | `boolean` | No | Cache the query result until slot projection changes. Defaults to `true`. |

## Type Safety

A single-element slot query is `T | null` and an `all: true` query is `T[]`, empty while nothing is assigned. Under standard decorators, any other field type does not compile: see [Typing Decorated Fields](/docs/decorators).

```typescript
@querySlot({ name: 'heading' }) heading!: HTMLHeadingElement | null;
@querySlot({ all: true }) items!: HTMLLIElement[];

focusHeading() {
	this.heading?.focus();
}
```

## Notes

- `@querySlot` returns elements only. Text nodes in projected content are ignored.
- Cache invalidation follows slot projection changes: later direct-host child mutations on a host whose children were authored as HTML, and every render of a host whose children a JSX view passes as a value.
- On a host fed by a JSX view, the default slot returns the top-level elements its children rendered to, and a named slot returns nothing: named regions are properties there. See [Slots](/docs/components/slots).
- Use [@query](/docs/decorators/query) for selector or `data-ref` queries over the rendered light DOM subtree.
