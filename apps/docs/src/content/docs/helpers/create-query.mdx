# createQuery

`createQuery` creates a live DOM query accessor bound to a host element. It is the functional equivalent of the [`@query`](/docs/decorators/query) decorator, designed for vanilla JS usage or cases where decorators are not available. `createQueryAll` is the equivalent of `@queryAll`.

## Usage

```typescript
import { RadiantElement } from '@ecopages/radiant';
import { createQuery, createQueryAll } from '@ecopages/radiant/helpers/create-query';

class UserProfile extends RadiantElement {
	#avatar = createQuery<HTMLImageElement>(this, '.avatar');
	#items = createQueryAll<HTMLElement>(this, '.item');

	get avatar() {
		return this.#avatar.value;
	}

	get items() {
		return this.#items.value;
	}
}

customElements.define('user-profile', UserProfile);
```

Each read of `.value` runs the lookup, with no cache. Both are unscoped: a selector reaches into nested hosts. To read a part the host owns by its `data-ref` name, use [`getRef`](/docs/components/radiant-element).

## Parameters

`createQuery<T>(target, selector)` and `createQueryAll<T>(target, selector)` accept:

| Parameter | Type | Required | Description |
| :-------- | :--- | :------- | :---------- |
| `target` | `Element` or `{ host: Element }` | Yes | The element host or controller to query within. |
| `selector` | `string` | Yes | CSS selector to match elements. |

## Return Value

Returns an object with a single `.value` getter:

- `createQuery<T>`: `T | null`, the first match or `null`.
- `createQueryAll<T>`: `T[]`, every match in document order, `[]` when nothing matches.
