# Installation

Radiant is the core package. Ecopages Signals provides its reactive layer. Ecopages JSX is the companion package for TSX rendering.

For the standard Radiant setup, install `@ecopages/radiant` with its `@ecopages/jsx` and `@ecopages/signals` peer dependencies.

That is the simplest setup today:

- `@ecopages/radiant` provides the custom-element and controller runtime
- `@ecopages/jsx` backs `render()` and the TSX authoring flow
- `@ecopages/signals` backs host reactivity, `@signal`, and resource helpers

You do not need to import JSX or Signals APIs directly in every Radiant component. A component can use `render()` without importing `@ecopages/jsx` symbols itself, and `@state` does not require importing `@ecopages/signals` in application code.

`@ecopages/radiant` declares `@ecopages/jsx` and `@ecopages/signals` as peer dependencies. `@ecopages/jsx` also declares `@ecopages/signals` as a peer dependency for signal-backed derived bindings such as `mapSubscribable(...)`.

Radiant and JSX must share a **single** Signals module instance within the application graph. Inlining `@ecopages/signals` into more than one app vendor chunk (or installing conflicting versions) breaks shared reactivity — for example, `@state` updates may not reach `createResource` when each chunk owns its own signals runtime.

## TypeScript Setup For JSX

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@ecopages/jsx"
  }
}
```
<br/>
Or enable it per file:

```tsx
/** @jsxImportSource @ecopages/jsx */
```

## TypeScript Setup For Decorators

Radiant decorators work with standard decorators, which TypeScript uses when `experimentalDecorators` is off, and with legacy decorators (`"experimentalDecorators": true`). The published types use `NoInfer`, so use TypeScript 5.4 or newer. Only standard decorators check field types against decorator options; see [Typing Decorated Fields](/docs/decorators#typing-decorated-fields).

## Which Packages To Install

- Install `@ecopages/radiant`, `@ecopages/jsx`, and `@ecopages/signals` for the standard Radiant setup.
- `@ecopages/jsx` is required for TSX authoring, `render()`, hydration helpers, and SSR rendering.
- `@ecopages/signals` backs `@signal`, host-owned async resources, and standalone reactive code. It is required by both Radiant and JSX.
