# External store cart

The cart lives in a store that is not a Radiant host: checkout, analytics, or another framework would write it. Two custom elements read slices of it. A plain **Add mug** button writes the store, not `@state`.

<ExternalStoreCart />

The badge uses `@fromStore` and binds `this.$.count`, so adding an item patches the number without re-running that host's `render()`. The list reads the items in `render()` because the row structure changed. See [External stores](/docs/signals/signals-external-store) and [@fromStore](/docs/decorators/from-store).
