# CalendarPopoverController

<p class="docs-lede">Open state, positioning, focus-out dismissal and mobile layout for a calendar popup.</p>

Reach for it for a date picker popup around a calendar.

## Import

```ts
import {
	CalendarPopoverController,
	createCalendarPopoverController,
	focusCalendarPickerDay,
} from '@ecopages/radiant-ui/controllers';
```

## Try it

The button opens the popup and focuses the selected day, today at first. The month grid comes from `buildCalendarMonth`, and picking a day sets the button label and closes the popup. Escape from inside the popup closes it and returns focus to the button; focus leaving the host closes it without moving focus. `portal` moves the popup while it is open, here into the example frame so the frame styles still reach it.

```ts
import { CalendarPopoverController } from '@ecopages/radiant-ui/controllers';
import {
	buildCalendarMonth,
	dateToIso,
	formatDisplayDate,
	formatMonthYear,
	getWeekStartsOn,
	getWeekdayLabels,
} from '@ecopages/radiant-ui/helpers';

export function mount(root: HTMLElement): () => void {
	const toggle = root.querySelector('button')!;
	const popup = root.querySelector<HTMLElement>('[data-box]')!;
	const locale = 'en-US';
	const today = new Date();

	popup.querySelector('[data-month]')!.textContent = formatMonthYear(today, locale);
	popup.querySelector('[data-weekdays]')!.replaceChildren(
		...getWeekdayLabels(locale, getWeekStartsOn(locale)).map((label) => {
			const cell = document.createElement('span');
			cell.textContent = label;
			return cell;
		}),
	);
	popup.querySelector('[data-days]')!.replaceChildren(
		...buildCalendarMonth(today.getFullYear(), today.getMonth(), { locale, today })
			.flat()
			.map((day) => {
				if (!day.inMonth) {
					return document.createElement('span');
				}
				const button = document.createElement('button');
				button.type = 'button';
				button.textContent = String(day.date.getDate());
				button.dataset.calendarDay = '';
				button.dataset.iso = day.iso;
				button.toggleAttribute('data-today', day.isToday);
				return button;
			}),
	);

	let open = false;
	let selected = dateToIso(today);
	const picker = new CalendarPopoverController({
		getHost: () => root,
		getAnchor: () => toggle,
		getFloating: () => popup,
		getOpen: () => open,
		getCalendar: () => popup,
		portal: true,
		getPortalContainer: () => root,
		getFocusIso: () => selected,
		getToggle: () => toggle,
		setOpenState: (next) => (open = next),
		onLayoutChange: () => {},
	});
	picker.attach();

	toggle.addEventListener('click', () => picker.setOpen(!open));
	popup.addEventListener('click', (event) => {
		const day = (event.target as HTMLElement).closest<HTMLElement>('[data-calendar-day]');
		if (!day) {
			return;
		}
		selected = day.dataset.iso!;
		toggle.textContent = formatDisplayDate(new Date(`${selected}T00:00`), locale);
		picker.closeAndRestoreFocus();
	});
	return () => picker.destroy();
}
```

`mount` runs once for each example element on the page, and the function it returns undoes it; see [how the examples run](/docs/controllers/overview#how-the-examples-run).

## Config

| Option               | Description                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| `getHost`            | The picker element. Focus inside it, or the popup, is inside.                                                 |
| `getAnchor`          | The element the popup sits beside.                                                                            |
| `getFloating`        | The popup.                                                                                                    |
| `getOpen`            | Whether the popup is open.                                                                                    |
| `getCalendar`        | The element that holds the `[data-calendar-day]` buttons.                                                     |
| `getFocusIso`        | The `YYYY-MM-DD` day to focus on open; the first available day when `undefined`.                              |
| `getToggle`          | The button that receives focus when the popup closes from inside.                                             |
| `portal`             | Move the popup out of its place while open. Default `false`; `updateConfig({ portal })` changes it.           |
| `getPortalContainer` | Where a portaled popup goes, read each time it opens. `document.body` when omitted or when it returns `null`. |
| `setOpenState`       | Writes the host's `open` state.                                                                               |
| `onLayoutChange`     | Called when the mobile layout viewport changes, before an open popup is repositioned.                         |

## Lifecycle

`attach()` starts the dismissal and a mobile layout listener; `destroy()` removes both and the popover. `setOpen(next)` writes the state, positions the popup and, on open, focuses the calendar day. Also `closeAndRestoreFocus()`, `suppressDismiss()` (skip the next focus-out, for a press on the toggle) and `syncPopover()`. `focusCalendarPickerDay(calendar, iso)` is the focus step on its own.

With a host, `createCalendarPopoverController(host, config)` does the same on connect and disconnect; see [bindController](/docs/controllers/bind-controller).

A portaled popup is no longer inside the host, so the date picker holds a reference to it, listens on it directly and sets the calendar's attributes itself rather than binding them through the host.

## Protected hooks

None. Value commit and selection mode stay in the date picker.
