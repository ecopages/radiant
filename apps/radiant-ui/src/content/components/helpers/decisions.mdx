# Decisions

<p class="docs-lede">Swipe direction from a delta, the wrap target of a focus trap, and a wrapped index.</p>

Reach for them for custom gestures, focus loops and option lists. The helpers are pure: no DOM at import time or in the call path, so they run on the server and in tests. Each result below is computed when the page is built, by running the call shown.

## Import

```ts
import {
	resolveSwipeDirection,
	DEFAULT_SWIPE_THRESHOLD_PX,
	resolveTrapMove,
	wrapCollectionIndex,
	SwipeDirection,
	SwipeAxis,
	SwipeOptions,
	TrapMove,
} from '@ecopages/radiant-ui/helpers';
```

## Swipe

`resolveSwipeDirection(dx, dy, options)` needs travel of at least `threshold` along the axis that also exceeds the travel on the other axis. It is the default of the `resolveDirection` hook of [SwipeController](/docs/controllers/swipe).

## Focus trap and collections

`resolveTrapMove` says where Tab goes inside a trapped surface, generic over the item so it needs no DOM. `wrapCollectionIndex` moves an active index by one and wraps.
