# Decisions

<p class="docs-lede">Swipe direction from a delta, the wrap target of a focus trap, a wrapped index, and where a floating surface goes.</p>

Reach for them for custom gestures, focus loops and option lists. The helpers are pure: no DOM at import time or in the call path, so they run on the server and in tests. Each result below is computed when the page is built, by running the call shown.


## Swipe

`resolveSwipeDirection(dx, dy, options)` needs travel of at least `threshold` along the axis that also exceeds the travel on the other axis. It is the default of the `resolveDirection` hook of [SwipeController](/docs/controllers/swipe).

## Focus trap and collections

`resolveTrapMove` says where Tab goes inside a trapped surface, generic over the item so it needs no DOM. `wrapCollectionIndex` moves an active index by one and wraps.

## Floating position

`computeFloatingCoords(anchor, size, placement, gap, viewport)` returns the fixed coordinates of a surface beside an anchor rect, flipping to the opposite side when it overflows and clamping on the cross axis. `computeFloatingPosition` also returns the resolved placement. The caller passes the viewport, so nothing here reads `window`; `applyFloatingPosition` in `@ecopages/radiant-ui/controllers` does that for an element.

```ts
const anchor = button.getBoundingClientRect();
const viewport = { width: window.innerWidth, height: window.innerHeight, padding: 8 };

const { coords, placement } = computeFloatingPosition(anchor, { width: 120, height: 28 }, 'bottom-start', 8, viewport);
```
