# Masks

<p class="docs-lede">Pattern masks such as (000) 000-0000 and locale date masks.</p>

Reach for them for formatted text input. The helpers are pure: no DOM at import time or in the call path, so they run on the server and in tests. Each result below is computed when the page is built, by running the call shown.

## Pattern masks

In a pattern `0` is a digit slot, `a` a letter and `*` any character; `{text}` is fixed text, `[...]` an optional section and `\` escapes the next character. Other characters are literals. `parseMaskPattern` turns a pattern into tokens that the other helpers use.

Two reads, two writes. `extractMaskInput` and `formatWithMask` work on the characters typed into the slots only. `extractUnmaskedValue` and `formatUnmaskedValue` work on the unmasked value, which also holds the `{text}`, so a mask `+{7} 000` shows `+7 123` for the unmasked `7123`. `applyInputMask` reads raw text that the user typed or pasted: it keeps the characters that fit the slots, in order, and skips the rest.

## Date masks

The mask and placeholder come from the locale, and typed digits map back to a date in the locale's field order.

<HelperResults
	rows={[
		{ code: "buildDateMaskPattern('en-US')", result: buildDateMaskPattern('en-US') },

		{ code: "applyDateMask('08212002', '00/00/0000')", result: applyDateMask('08212002', '00/00/0000') },
		{ code: "maskedDigitsToParts('08212002', 'en-US')", result: maskedDigitsToParts('08212002', 'en-US') },

	]}
