# Helpers

<p class="docs-lede">
	Helpers are the decisions and formatting behind the components: date math, masks, number parsing, ordering. They are
	plain functions with no DOM.
</p>

```ts
import { cycleValue } from '@ecopages/radiant-ui/helpers';

cycleValue(['light', 'dark', 'system'], 'system'); // 'light'
```

Nothing in the entry touches the DOM at import time or when called, so helpers run on the server and in tests. Anything that reads or sets DOM state is a [controller](/docs/controllers/overview) utility instead. The entry is tree-shakeable. Every export has a TSDoc example, and each page below shows the results of real calls, computed when the docs are built.

Use a helper, not a controller, for anything that only maps input to output.
