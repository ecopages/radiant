# Text filter

<p class="docs-lede">Case- and accent-insensitive contains, for filtering a list as the user types.</p>

Reach for it to filter options while the user types. The helpers are pure: no DOM at import time or in the call path, so they run on the server and in tests. Each result below is computed when the page is built, by running the call shown.

## Import

```ts
import { textContains, TextFilterSensitivity } from '@ecopages/radiant-ui/helpers';
```

## Sensitivity

`base` (default) ignores case and accents, `accent` ignores case only, `case` is a literal substring match. An empty query matches everything.
