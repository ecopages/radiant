# Cycle value

<p class="docs-lede">The next value in a list, wrapping from the last to the first.</p>

Reach for it for a cycle toggle. The helpers are pure: no DOM at import time or in the call path, so they run on the server and in tests. Each result below is computed when the page is built, by running the call shown.

## Import

```ts
import { cycleValue } from '@ecopages/radiant-ui/helpers';
```

## Cycling

A missing or unknown current value gives the first entry, so stale or unset state recovers. An empty list throws a `RangeError`.
