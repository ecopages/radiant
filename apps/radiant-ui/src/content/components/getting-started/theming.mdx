# Theming

<p class="docs-lede">
	Radiant UI ships one carefully tuned Basalt default. The optional Radiant Themes package adds ready-made themes
	and variants built from the same composable color, spacing, radius, and semantic-role layers.
</p>

<DesignTokenPanel />

## Start with the default

Import the default theme and the component stylesheet in the application entry stylesheet. The default uses Basalt
colors, comfortable spacing, and the soft radius scale.

```css
@import 'tailwindcss';
@import '@ecopages/radiant-ui/themes/default';
@import '@ecopages/radiant-ui/styles.css';
```

## Add optional themes

Install `@ecopages/radiant-themes` to use its GitHub, VS Code, and Vercel themes. Each full theme is composed from
shared foundation tokens, color palettes, semantic roles, and optional component tokens.

```css
@import 'tailwindcss';
@import '@ecopages/radiant-themes/github';
@import '@ecopages/radiant-ui/styles.css';
```

`github/compact`, `vscode/compact`, and `vercel/compact` are convenient variants. They reuse the same theme definition
and compose the compact spacing pack; they do not duplicate theme tokens. The live preview on this page loads the
published theme entries so you can compare them in light and dark modes.

## Tune the Basalt palette

Basalt derives matching color scales from three OKLCH seeds. Set primary and secondary to retune the brand roles, and
neutral to retune the page and surface tones:

```css
:root {
	--rui-neutral: oklch(62% 0.014 265);
	--rui-primary: oklch(52% 0.19 264);
	--rui-secondary: oklch(63.5% 0.095 195);
}
```

The three seed variables control the neutral, primary, and secondary scales; semantic roles map those scales to
component-facing names such as `--primary`, `--surface`, and `--error`. Info follows the primary seed and success follows
the secondary seed. Error and warning keep their accessible defaults.

## Layer spacing and shape

Use `compact` where information density matters and `wide` where composition needs more air. Both packs scale
`--size-control-*` with `--space-8`, `--space-10`, and `--space-12`, so buttons and inputs change height as well as
padding. Soft radius is the default; use `sharp` for square surfaces.

Tune default geometry and border strength with three scalar variables. The spacing and radius variables scale the
selected packs; border alpha controls the translucent Basalt border.

```css
:root {
	--rui-density: 1;
	--rui-radius-scale: 1;
	--rui-border-alpha: 18%;
}
```

```css
@import '@ecopages/radiant-ui/tokens/spacing/compact';
@import '@ecopages/radiant-ui/tokens/radius/sharp';
```

Layer a spacing or radius pack after the theme when a product needs a different density or shape. The default theme
and optional theme entries share these axes, so they can be combined independently.

```css
@import '@ecopages/radiant-ui/themes/default';
@import '@ecopages/radiant-ui/tokens/spacing/compact';
@import '@ecopages/radiant-ui/tokens/radius/sharp';
@import '@ecopages/radiant-ui/styles.css';
```

## Migrate from the previous theme imports

The default theme now means Basalt with soft radius. If your app relied on the former Glacier default, tune Basalt's
primary, secondary, and neutral seeds to match your product colors. The old `themes/glacier`, `themes/aurora`,
`tokens/colors/glacier`, `tokens/colors/aurora`, `tokens/presets/colors/ember`, and aggregate `tokens/colors/palettes`
imports have no direct replacements. Install `@ecopages/radiant-themes` for GitHub, VS Code, or Vercel instead.

Replace `@ecopages/radiant-ui/themes/default-compact-soft` with the default theme and compact spacing. This keeps
compact spacing and soft radius but changes the colors to Basalt; the old entry used Aurora colors, which have no direct
replacement. Soft radius is already included:

```css
@import '@ecopages/radiant-ui/themes/default';
@import '@ecopages/radiant-ui/tokens/spacing/compact';
```

## Build a custom colour theme

Define semantic colour roles in a stylesheet loaded after the base theme. Components consume these roles (`bg-primary`,
`text-on-surface`, …), not palette steps such as `carbon-blue-500`.

Override the roles your product needs. A complete list, with live swatches, is on the [Tokens](/docs/getting-started/tokens)
page.

```css
:root {
	--primary: oklch(52% 0.19 264);
	--on-primary: oklch(100% 0 0);
	--primary-container: oklch(93% 0.04 264);
	--on-primary-container: oklch(30% 0.11 264);

	--background: oklch(98.2% 0.004 265);
	--on-background: oklch(22% 0.008 265);
	--surface: oklch(96% 0.006 265);
	--on-surface: var(--on-background);
	--border: oklch(74% 0.012 265);
	--focus-ring: var(--primary);
}
```

Dark mode changes the theme colours, including palette values and their semantic role mappings. Spacing, radius,
elevation, typography, and motion stay mode-independent unless a theme documents otherwise. Toggle dark mode in the
docs header to preview the current theme's dark colors.

See [Tokens](/docs/getting-started/tokens) for the spacing scale, radius scale, and every semantic colour role.
