# Modal dialog

<p class="docs-lede">
	A dialog that holds focus and the page still while it is open, and gives both back when it closes.
</p>

## Goal

A confirmation, a form in an overlay or a lightbox: while it is open the user works only in the dialog. Tab loops inside it, what is behind does not scroll, Escape or a press outside closes it, and focus goes back to the button that opened it.

## Primitives

- [PortalController](/docs/controllers/portal) moves the dialog out of the element it lives in and puts it back on close, so no overflow or stacking context of its parents clips it. Without `getContainer` it goes to `document.body`; the example passes the example frame instead, so the dialog stays inside it and the frame styles still apply. It also carries the theme of the place it left.
- [FocusTrapController](/docs/controllers/focus-trap) moves focus into the dialog on attach, loops Tab and Shift+Tab inside it, and returns focus on destroy: to the previously focused element, or to the control `getReturnFocus` names.
- [ScrollLockController](/docs/controllers/scroll-lock) stops the page from scrolling, and counts, so two modals open at once release it only when both are closed. This site is an app shell where the article column scrolls and the document does not, so the example passes that column as `getTarget`; without `getTarget` it locks the page, which is what you want in a project whose page scrolls.
- [DismissController](/docs/controllers/dismiss) reports Escape and a press outside the dialog. Focus leaving is not listened to, because the trap already keeps it inside.

Left to the recipe: the open and close function that attaches and destroys the four together, and `aria-modal` and a label on the dialog. None of them makes the rest of the page `inert`; a modal that must also block the pointer on the page or find-in-page sets `inert` itself.

Escape stays with DismissController: its `onDismiss` closes the dialog, and the close calls `trap.destroy()`, which is where `getReturnFocus` is read. The trap has no Escape of its own. For a non-modal surface, such as an inline panel that should hold focus only while the user works in it, pass `getEnabled: () => false` (or a getter that reads the panel's state) so Tab can leave without detaching the trap; this dialog is modal and leaves it out.

## Example

Open the dialog: the example frame dims behind it. Press Tab to see focus stay inside, then close it with a button, Escape or a press on the dimmed area. Cancel, Escape and a press outside return focus to Open dialog; Delete returns it to Next item through `getReturnFocus`. The two forms below behave the same.

```ts
import {
	DismissController,
	FocusTrapController,
	PortalController,
	ScrollLockController,
} from '@ecopages/radiant-ui/controllers';

export function mount(root: HTMLElement): () => void {
	const opener = root.querySelector<HTMLElement>('[data-open]')!;
	const layer = root.querySelector<HTMLElement>('[data-layer]')!;
	const dialog = root.querySelector<HTMLElement>('[data-dialog]')!;
	const next = root.querySelector<HTMLElement>('[data-next]')!;
	const status = root.querySelector('[data-status]')!;

	const portal = new PortalController({ getNode: () => layer, getContainer: () => root });
	let returnTo: HTMLElement | null = null;
	const trap = new FocusTrapController({ getSurface: () => dialog, getReturnFocus: () => returnTo });
	const lock = new ScrollLockController({
		getTarget: () => root.closest<HTMLElement>('.docs-layout__content') ?? document.documentElement,
	});
	const dismiss = new DismissController({
		getSurface: () => dialog,
		triggers: ['pointer', 'escape'],
		onDismiss: () => close('Dialog closed'),
	});

	function open(): void {
		layer.hidden = false;
		portal.attach();
		lock.attach();
		trap.attach();
		dismiss.attach();
		status.textContent = 'Dialog open';
	}

	function close(message: string): void {
		dismiss.destroy();
		layer.hidden = true;
		trap.destroy();
		returnTo = null;
		lock.destroy();
		portal.destroy();
		status.textContent = message;
	}

	opener.addEventListener('click', open);
	dialog.querySelector('[data-confirm]')!.addEventListener('click', () => {
		returnTo = next;
		close('Deleted');
	});
	dialog.querySelector('[data-close]')!.addEventListener('click', () => close('Dialog closed'));
	return () => close('Dialog closed');
}
```

`mount` runs once for each example element on the page, and the function it returns undoes it; see [how the examples run](/docs/recipes/overview#how-the-examples-run).

```ts
import { RadiantElement, customElement, onEvent, query } from '@ecopages/radiant';
import {
	DismissController,
	FocusTrapController,
	PortalController,
	ScrollLockController,
} from '@ecopages/radiant-ui/controllers';

/**
 * @remarks
 * The four controllers are constructed directly, not through `createX(this, ...)`: they start and stop with the
 * dialog, not with the element's connection. `registerCleanupCallback` releases them if the element leaves the page
 * while the dialog is open.
 */
@customElement('recipe-modal')
export class RecipeModal extends RadiantElement {
	@query({ selector: '[data-next]' }) private next!: HTMLElement;
	@query({ selector: '[data-layer]' }) private layer!: HTMLElement;
	@query({ selector: '[data-dialog]' }) private dialog!: HTMLElement;
	@query({ selector: '[data-status]' }) private status!: HTMLElement;

	private returnTo: HTMLElement | null = null;
	private readonly portal = new PortalController({ getNode: () => this.layer, getContainer: () => this });
	private readonly trap = new FocusTrapController({
		getSurface: () => this.dialog,
		getReturnFocus: () => this.returnTo,
	});
	private readonly lock = new ScrollLockController({
		getTarget: () => this.closest<HTMLElement>('.docs-layout__content') ?? document.documentElement,
	});
	private readonly dismiss = new DismissController({
		getSurface: () => this.dialog,
		triggers: ['pointer', 'escape'],
		onDismiss: () => this.close('Dialog closed'),
	});

	constructor() {
		super();
		this.registerCleanupCallback(() => this.close('Dialog closed'));
	}

	@onEvent({ selector: '[data-open]', type: 'click' })
	open(): void {
		this.layer.hidden = false;
		this.portal.attach();
		this.lock.attach();
		this.trap.attach();
		this.dismiss.attach();
		this.status.textContent = 'Dialog open';
	}

	@onEvent({ selector: '[data-confirm]', type: 'click' })
	confirm(): void {
		this.returnTo = this.next;
		this.close('Deleted');
	}

	@onEvent({ selector: '[data-close]', type: 'click' })
	cancel(): void {
		this.close('Dialog closed');
	}

	private close(message: string): void {
		this.dismiss.destroy();
		this.layer.hidden = true;
		this.trap.destroy();
		this.returnTo = null;
		this.lock.destroy();
		this.portal.destroy();
		this.status.textContent = message;
	}
}
```

The four controllers are built directly because the dialog starts and stops them, and the `@onEvent` listeners keep working after the layer is portaled because the container is the element itself. The cleanup callback closes the dialog if the element is removed while the dialog is open. What the Radiant form removes: the `mount` function and its registration, the cleanup to return and call, and the re-run after a client-side navigation.
