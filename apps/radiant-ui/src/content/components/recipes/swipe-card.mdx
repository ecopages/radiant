# Swipe to dismiss

<p class="docs-lede">A card that follows the pointer, dismissed by a horizontal swipe, and with a button that does the same.</p>

## Goal

A notification, a suggestion or a message in a feed that the user clears with a gesture. A gesture is never the only way: the button is the keyboard and assistive technology path, and both paths end in the same function.

## Primitives

- [PointerDragController](/docs/controllers/pointer-drag) reports the drag, so the card follows the pointer: the recipe writes `--swipe-dx` and `--swipe-opacity` on it and the CSS translates and fades it, with no transition while `data-dragging` is set and a transition on release. Its `canStart` keeps a press on the button from starting a drag.
- [resolveSwipeDirection](/docs/helpers/decisions) decides on release from the drag's `dx`, `dy` and `elapsedMs`: a long drag counts, and so does a short quick flick (`minVelocity`) as long as it is clearly sideways (`dominance`). Past the decision the card flies out and is dismissed; otherwise it springs back.

The recipe uses one `PointerDragController` and the pure decision rather than a second `SwipeController` on the same card: `SwipeController` is itself a `PointerDragController`, so two would listen for the same press twice and finish in an order the recipe does not control. The time comes from the `elapsedMs` of the drag's end.

Left to the recipe: what dismissing does (here it waits for the fly-out animation, hides the card and says so in a live region) and moving focus on to the restore button, since the focused element just left the page. A card that only needs the decision and no feedback uses [SwipeController](/docs/controllers/swipe).

## Example

Drag the card sideways at least 48 px, or flick it faster than 0.5 px per ms over at least 16 px, then release. A shorter or slower drag springs back, and so does one that is not at least twice as far sideways as vertically. Or press the Dismiss button.

```ts
import { PointerDragController } from '@ecopages/radiant-ui/controllers';
import { resolveSwipeDirection } from '@ecopages/radiant-ui/helpers';

export function mount(root: HTMLElement): () => void {
	const card = root.querySelector<HTMLElement>('[data-card]')!;
	const dismissButton = root.querySelector<HTMLElement>('[data-dismiss]')!;
	const restoreButton = root.querySelector<HTMLElement>('[data-restore]')!;
	const status = root.querySelector('[data-status]')!;

	function setShown(shown: boolean, message: string): void {
		card.hidden = !shown;
		restoreButton.hidden = shown;
		status.textContent = message;
		card.style.setProperty('--swipe-dx', '0px');
		card.style.setProperty('--swipe-opacity', '1');
	}

	function follow(dx: number): void {
		const distance = Math.min(Math.abs(dx) / card.offsetWidth, 1);
		card.style.setProperty('--swipe-dx', `${dx}px`);
		card.style.setProperty('--swipe-opacity', `${1 - distance / 2}`);
	}

	const drag = new PointerDragController({
		getTarget: () => card,
		capture: false,
		canStart: (event) => !(event.target instanceof Element && event.target.closest('button')),
		onStart: () => {
			card.dataset.dragging = '';
		},
		onMove: ({ dx }) => follow(dx),
		onEnd: ({ reason, dx, dy, elapsedMs }) => {
			delete card.dataset.dragging;
			const direction =
				reason === 'release'
					? resolveSwipeDirection(dx, dy, { minVelocity: 0.5, dominance: 2, elapsedMs })
					: null;
			if (!direction) {
				follow(0);
				return;
			}
			follow(direction === 'left' ? -card.offsetWidth : card.offsetWidth);
			Promise.allSettled(card.getAnimations().map((animation) => animation.finished)).then(() =>
				setShown(false, `Card dismissed, swiped ${direction}`),
			);
		},
	});
	drag.attach();

	dismissButton.addEventListener('click', () => {
		setShown(false, 'Card dismissed');
		restoreButton.focus();
	});
	restoreButton.addEventListener('click', () => {
		setShown(true, 'The card is shown');
		dismissButton.focus();
	});
	return () => drag.destroy();
}
```

`mount` runs once for each example element on the page, and the function it returns undoes it; see [how the examples run](/docs/recipes/overview#how-the-examples-run).
