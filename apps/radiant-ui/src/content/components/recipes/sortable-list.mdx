# Sortable list

<p class="docs-lede">
	A list whose items the user reorders by dragging or from the keyboard, with each step announced.
</p>

## Goal

A to-do list, a playlist or a priority ranking: the order is data the user edits. The list keeps one tab stop, lifts an item with Space, moves it with the arrow keys and drops it with Space, and a drag with the pointer does the same. A live region says what happened.

## Primitives

- [SortableController](/docs/controllers/sortable) decides where the item lands, by pointer or keyboard, and announces each step. It never moves a node, so the recipe keeps the order itself.
- [reorder](/docs/helpers/ordering) turns the `from` and `to` of a change into the new array, so the order is one array the recipe owns.
- [RovingController](/docs/controllers/roving) gives the list one tab stop and moves it with the arrows. Its `enabled` returns `false` while an item is lifted, so the arrow keys that steer the lifted item do not also move focus.

Left to the recipe: the order array and writing it to the DOM in `onChange`, and refocusing the dropped item.

## Example

Tab into the list, press Space on an item, move it with the arrow keys and press Space to drop it, or drag it with the pointer.

```ts
import { RovingController, SortableController } from '@ecopages/radiant-ui/controllers';
import { reorder } from '@ecopages/radiant-ui/helpers';

const root = document.querySelector('[data-example="sortable-list"]')!;
const list = root.querySelector('ul')!;
const status = root.querySelector('[data-status]')!;

let items = [...list.children] as HTMLElement[];

const roving = new RovingController({
	getItems: () => items,
	getTarget: () => list,
	orientation: 'vertical',
	enabled: () => sortable.getState() === null,
});

const sortable = new SortableController({
	getContainer: () => list,
	getItems: () => items,
	announce: (message) => (status.textContent = message),
	onChange: ({ item, from, to }) => {
		items = reorder(items, from, to);
		list.append(...items);
		roving.focus(item);
	},
});

sortable.attach();
roving.attach();
roving.sync();
```
