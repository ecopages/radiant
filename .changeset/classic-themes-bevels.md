Rework Windows 95 around its native two-tone bevels, and Mac OS Classic as Mac OS 9 Platinum, using the Mac OS 8 Human Interface Guidelines metrics: seven system greys, black-outlined push buttons with a default ring, bevelled check boxes, shaded radios, trapezoid tabs, and striped title bars. Their dark modes now use dark fields, which fixes white-on-white select and input text. Button treatments vary by theme: Cloudflare uses a contrast-safe orange primary fill, VS Code uses its blue fill for dark-mode filled buttons, and Cloudflare, GitHub, and Vercel use saturated fills with white text for dark-mode destructive buttons. Switch tracks are visible again in Cloudflare, Vercel, and macOS, and alerts keep their tone colors.
