Fix controller and host lifecycle gaps. A controller `@signal` now hydrates from its scoped `id:field` hydration script. Under legacy decorators a controller `@prop` written before `connect()` keeps its value, and `@prop` adopts the member bootstrapped at construction instead of replacing it. A controller whose connect callback disconnects and reconnects it runs its update cycle once. Initial update emits no longer run `@bindTo` and `registerUpdateCallback` callbacks while the host is not observed. On connect, update callbacks are subscribed before the diff runs, so a write during the diff reaches them once. A callback that disconnects the host stops the rest of a member's callbacks, one that is unregistered during the pass is skipped, and a stale `observeMembers()` stop function no longer ends a newer observation. Under legacy decorators, server rendering a controller no longer resolves a declared but unassigned `@prop` to `undefined` instead of its `defaultValue`.
