# Radiant Vite Exploration

This playground is the plain client-side Vite sandbox for the existing Radiant light-DOM patterns.

It is intentionally separate from the Vite + Nitro playground:

- `playground/vite` stays focused on client-only demos, imperative rendering, Kita-based wrappers, and existing `RadiantElement` patterns
- `playground/vite-nitro` owns the JSX-first `RadiantComponent` work, SSR, and hydration experiments

The old `RadiantElementJsx` exploration files have been removed from this playground so the two sandboxes no longer overlap.
