# radiant-ui

Accessible light-DOM UI components built with [`@ecopages/radiant`](https://radiant.ecopages.app) and `@ecopages/jsx`.

Package: **`@ecopages/radiant-ui`**. Custom elements use the **`rui-*`** tag prefix. Public TypeScript types and JSX helpers use the **`Rui*`** prefix (for example `RuiDisclosure`, `RuiButton`).

This is not a React Storybook. Stories use Radiant custom elements and `@ecopages/jsx`.

## Component tiers

Not every entry under **Components/** is a full APG widget. Read the component TSDoc before treating it as a complete pattern:

| Tier | Meaning | Examples |
|------|---------|----------|
| **Native** | Thin styling / wiring around platform controls | `RuiButton`, Switch, Checkbox, Slider (single + range), Meter, Radio Group |
| **Composite** | Custom element implements APG roles, states, and keyboard model | Tabs, Dialog, Disclosure (+ Disclosure Group), Menu Button, Menubar, Listbox, Combobox, Tree, Treegrid, Toolbar, Grid, Carousel (transitions, indicators, rotation control), Window Splitter, Tooltip |
| **Shell** | Coordinator / structure — consumers compose content or own interaction beyond labeling | Feed, Navigation Menu (exclusive disclosure panels for megamenus) |

Each composite component's TSDoc links the [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/) pattern it targets.

## Conventions

- One directory per component in `src/components/ui/<name>/`:
  - `<name>.script.ts` or `<name>.script.tsx` — custom element
  - `<name>.tsx` — JSX view linked via `defineRadiantView` (or a presentational helper like `RuiButton`)
  - `<name>.css`, `<name>.stories.tsx`, `index.ts`
- Events use the `rui-*` namespace (`rui-change`, `rui-close`).
- Stateful props (`open`, `value`, `index`, `autoplay`, …) are reactive via `@onUpdated` unless a component documents them as initial-only.
- Stories are render-mode agnostic. Use the toolbar **Radiant render** control to spot-check SSR (`ssr-hydrate` / `ssr-static`) on any story.

| Mode | Behavior |
|------|----------|
| `client` | Mount JSX / custom elements in the browser |
| `ssr-hydrate` | `renderComponent` on the Vite server, inject markup, load client module, hydrate |
| `ssr-static` | Server markup only |

## Using the library

```ts
import '@ecopages/radiant-ui/disclosure'; // registers <rui-disclosure> and <rui-disclosure-group>
import { RuiDisclosure, RuiDisclosureGroup } from '@ecopages/radiant-ui/disclosure';
```

The root entry registers every custom element:

```ts
import '@ecopages/radiant-ui';
```

Presentational helpers that are not custom elements (today: `RuiButton`) are still imported from their subpath:

```ts
import { RuiButton } from '@ecopages/radiant-ui/button';
```

## Docs-only APG guidance

Link, Table, and Landmarks are not shipped as widgets here — use native HTML and document landmarks in app layouts.
